# Матч-центр КХЛ

> Сбор данных из ресурсов КХЛ, для отображения на сайтах и в мобильных приложениях клубов.

## О проекте
Проект работает на базе решений для бэкенда матч-центра хоккейного клуба "Авангард", и отчасти является тестовым полигоном для обкатки изменений.
В основе лежит short polling опрос сервисов КХЛ.

Основные функции: 
- Обработка текстовых трансляций с минимальной задержкой - до 5 секунд от обновления трансляции
- Отправка уведомлений об игровых событиях в мобильные приложения (пуши FCM/HCM)
- Cбор исторических данных: календари, результаты, статистика игроков


## Стек
- Python>=3.14+
- FastAPI>=0.141
- PostgreSQL 15
- Docker, docker-compose

## Быстрый старт
```bash
git clone ...
cd ...
docker compose up --build
```

По умолчанию приложение собирается в prod окружение и доступно на порту 8005, изменить можно при помощи переменных окружения BUILD_TARGET и EXTERNAL_APP_PORT, например
```bash
BUILD_TARGET=dev EXTERNAL_APP_PORT=8000 docker compose up --build
```

Документация для доступного на данный момент API http://localhost:8005/docs

## Ближайшие задачи

- Создание в БД профилей игроков
- Сохранение событий, статистики и других связанных с игрой данных из трансляции в БД
- Сбор данных о карьере игроков
- Отправка уведомлений об игровых событиях через FCM/HCM
- WS каналы для доступа клиетов к обновлениям текущих игр

Функционал переносится по мере появления свободного времени.
